# 乌鸦送信 · App Logo 设计说明

## 设计概念
以参考图（乌鸦坐飞机叼信件）为蓝本，简化为扁平化 App 图标：
- **主体**：圆滚滚的深色乌鸦站在白色客机机背上，单翅上扬，橙色喙叼着一封信封
- **背景**：天空蓝渐变（#6DB3F8 → #2F5BC0），点缀两朵半透明的云
- **风格**：扁平矢量、3 主色（深炭黑 / 白 / 蓝）+ 1 点缀色（橙 #F5A623），iOS 圆角矩形（rx=228）

## 交付文件
| 文件 | 用途 |
|---|---|
| `logo.svg` | 矢量源文件，可无限缩放、方便改色改版 |
| `logo-1024.png` | App Store / 应用市场上架主图 |
| `logo-512.png` | 安卓 / 网页常用尺寸 |
| `logo-192.png` | PWA / 小图标 |
| `render.js` | 重导出脚本（Playwright 渲染 SVG → PNG） |

## 可继续迭代的方向
- 深色 / 单色（线稿）变体，用于启动页或水印
- 调整乌鸦表情、信封角度或背景配色
- 输出透明背景（无圆角底板）版本
